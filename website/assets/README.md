# Website-Assets

Stand: 2026-04-25

Dieser Ordner ist bewusst leer, bis lokale Graviton-Screenshots als
Projektbelege erzeugt wurden.

Regeln fuer diesen Website-Prototyp:

- keine externen Bilder
- keine Stock-Weltraumbilder
- keine Addon-Icons
- keine Rendering-Referenztexturen als Projektbeleg
- echte Bilder erst nach lokaler Aufnahme aus einer Graviton-Szene

Geplante Quellen:

- lokale Root-Overview-Aufnahme
- lokale Survey- oder Readout-Ansicht
- lokale Inspector- oder Life-Detail-Ansicht

Bis diese Aufnahmen vorliegen, bleiben die Bildflaechen im Onepager als
`Platzhalter - Aufnahme ausstehend` markiert.
